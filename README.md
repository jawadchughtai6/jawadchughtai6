# Hi, I'm Jawad Chughtai 👋

**Senior Software Engineer — Python/Django & Generative AI**

I build production AI systems that businesses actually run on.

7+ years of backend engineering. The last 3 focused on shipping LLM-powered products — not demos, not notebooks. Real users, real uptime requirements.

## 🔧 What I work on

- 🤖 **Agentic workflows** — multi-agent, multi-turn tool-calling systems with LangGraph & LangChain
- 🧠 **LLM orchestration** — unified clients across OpenAI, Anthropic & Gemini (LiteLLM), with cost & token tracking, fallbacks, and evals
- 🎙️ **AI voice agents** — real-time telephony, sub-second latency, barge-in handling, call transfers, post-call webhooks
- 📚 **RAG pipelines** — vector search (Qdrant), embeddings, retrieval over messy real-world documents
- 🔌 **Deep integrations** — HubSpot, Salesforce, Zoho, Slack, Google Calendar, Calendly, Greenhouse, Lever & more
- 🏗️ **The backend underneath it all** — Django/DRF APIs, Celery pipelines, PostgreSQL, Redis, Docker
